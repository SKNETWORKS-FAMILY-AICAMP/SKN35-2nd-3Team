# 정제 데이터 가이드 (2026-08-23 기준)

드라이브에 같이 올라온 데이터 파일을 바로 쓸 수 있도록 컬럼 설명과 요약 통계를 정리한 문서입니다. 원본 다운로드 방법이나 업종/모델링 방향 같은 배경은 저장소의 `PROJECT_BRIEF.md`를 참고하세요.

## 파일 구성

- `all_industries_features.csv` — 인허가 6개 업종(일반음식점·숙박업·미용업·세탁업·목욕장업·PC방) 전국 통합, 2024년 이전 폐업 건 제외, **1,191,979행**
- `retail_seoul_features.csv` — 인허가 대상이 아닌 소매업 4종(편의점·폰케이스판매점·무인매점·인형뽑기), 서울만, **13,599행**

두 파일 다 **모델링에는 이 `_features.csv` 버전을 쓰세요** (같은 이름의 `_clean.csv`는 밀집도/대중교통 컬럼이 빠진 중간 산출물).

## 데이터 품질 보정 안내

- **지오코딩 오류 좌표 2건**: 서로 다른 상호의 두 업체가 대한민국 범위 밖의 동일 좌표를 갖고 있던 사례를 찾아 좌표/경도/위도를 결측 처리했습니다.
- **개업일자 placeholder 의심 120건**: 1950년 이전 개업일자(그중 23건은 정확히 `1900-05-31`로 동일) — 실제 개업일이 아니라 "날짜 모름"을 나타내는 기본값으로 추정, 원본 개업일자는 남기되 `tenure_days`/`tenure_years`/`개업연도`만 결측 처리했습니다. (보정 전 tenure_years 최댓값 126.6년 → 보정 후 74.8년)
- **2024년 이전 폐업 건 제외**: 전체 2,974,914행 중 1,782,935건(60%)이 "이미 2024년 이전에 폐업"인데 y=0(생존)으로 잡혀 있었습니다. 업종밀집도·대중교통 접근성 피처가 "오늘" 기준값이라 오래전 폐업 건에 붙이면 실제 폐업 당시 환경과 무관한 값을 학습시키게 되어 제외했습니다 — y=0은 이제 "현재 영업 중"만을 의미합니다. 제외 후 1,191,979행(y=1 239,020건, 20.1%)

**정상인데 극단값처럼 보여서 그대로 둔 것들**: 좌표 결측 20.5만 건(원본 자체 결측, 임의로 채우지 않음) / 폐업일자 결측 95만 건("현재 영업 중"이라는 정상 의미) / 최근접버스정류장 거리 최댓값 142km(백령도 실제 소재지) / 최근접지하철역 거리 최댓값 228km(제주 가파도 실제 소재지) / 업종밀집도 최댓값 877(부산 서면 상권, 실제 고밀도 지역).

## 컬럼 설명

### `all_industries_features.csv`

| 컬럼 | 타입 | 설명 |
|---|---|---|
| 업종명 | 문자열 | `일반음식점`/`숙박업`/`미용업`/`세탁업`/`목욕장업`/`PC방` |
| 사업장명 | 문자열 | 상호명 |
| 개업일자 | 날짜 | 인허가일자 |
| 폐업일자 | 날짜 | 현재 영업 중이면 결측 |
| 영업상태 | 문자열 | `영업/정상` 또는 `폐업` |
| 소재지주소 | 문자열 | 지번주소 우선, 없으면 도로명주소 |
| 좌표X, 좌표Y | 실수 | 원본 좌표(EPSG:5174) — 보통 안 씀 |
| 경도, 위도 | 실수 | WGS84 변환값. 지도/거리계산엔 이 컬럼 사용 |
| tenure_days, tenure_years | 실수 | 존속기간 = (폐업일자 또는 오늘) − 개업일자 |
| 개업연도 | 정수 | 개업일자의 연도 |
| **y** | 0/1 | **타깃.** 1 = 폐업일자가 2024-01-01 이후, 0 = 현재 영업 중 (2024년 이전 폐업 건은 데이터셋에서 아예 제외됨) |
| 업종밀집도 | 정수 | 반경 300m 내 같은 업종·현재 영업 중인 점포 수(자기 제외) |
| 최근접버스정류장_거리m | 실수 | 가장 가까운 버스정류장까지 거리(m) |
| 최근접지하철역_거리m | 실수 | 가장 가까운 지하철역까지 거리(m) |

### `retail_seoul_features.csv`

인허가 대상이 아니라 정확한 개업/폐업일자가 없음 — **스냅샷 두 시점(2025-06-30 vs 2026-06-30) 비교로 폐업 추정**. 위 파일과 y의 신뢰도 성격이 다름.

| 컬럼 | 타입 | 설명 |
|---|---|---|
| 업종명 | 문자열 | `편의점`/`폰케이스판매점`/`무인매점`/`인형뽑기` |
| 사업장명 | 문자열 | 상호명 |
| 소재지주소 | 문자열 | 지번주소 우선, 없으면 도로명주소 |
| 경도, 위도 | 실수 | WGS84 (원본 제공값 그대로) |
| 상가업소번호 | 문자열 | 원본 식별자, 스냅샷 매칭 키 |
| **y** | 0/1 | **타깃.** 1 = 2025-06-30엔 있었는데 2026-06-30엔 없음(폐업 추정), 0 = 생존 추정. ⚠️ 근사치 — 업종 재분류/상호명 변경으로 인한 오탐 가능성 있음 |
| 업종밀집도 | 정수 | 반경 300m 내 같은 업종·2026-06-30 시점 생존 점포 수 |
| 최근접버스정류장_거리m | 실수 | 가장 가까운 버스정류장까지 거리(m) |
| 최근접지하철역_거리m | 실수 | 가장 가까운 지하철역까지 거리(m) |

개업일자/tenure 컬럼이 없음(원본에 없음) — 두 파일을 합쳐서 쓸 땐 이 차이를 감안하세요.
